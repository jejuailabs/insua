## 이미지에서 읽어낸 것 vs 추론한 것

**직접 확인됨**

- 레이아웃, 컴포넌트 배치, 섹션 순서
- 텍스트 문구 (인사말, 라벨, 버튼명)
- 4가지 색 변형이 존재한다는 사실
- 등급 배지 색이 테마와 무관하게 유지된다는 점

**추론/근사치 (조정 가능)**

- 정확한 hex 값 — 눈으로 읽은 근사치다
- 폰트 패밀리 — Pretendard 계열로 판단
- 간격·라디우스 수치
- 라이트/다크 각 팔레트의 대응 관계 (이미지는 팔레트별로 1개 모드만 보여줌)

**이미지에 없어서 새로 정한 것**

- 연락 임박 표시 (`docs/06` §5)
- 반경 필터 UI (`docs/08` §5)
- 어드민 콘솔 전체 (`docs/09`)
- 빈 상태 화면들

새로 정한 것들은 문서에 이유를 적어뒀다. 이미지와 충돌하면 **이미지가 우선**이다.
